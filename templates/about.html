Academic MCA Project Synopsis

ResQPaws: Intelligent Animal Emergency Response and Rescue Management System

Designed and developed at Dev Bhoomi Uttarakhand University (DBUU), Dehradun.

ResQPaws bridges the critical time gap between discovering an injured animal and getting professional veterinary care. It features a complete pipeline of OpenCV image preprocessing, YOLOv8 visual object detection, automated severity estimation, and LLM AI first-aid triage.

ResQPaws Architecture

Image $\to$ OpenCV $\to$ YOLOv8 $\to$ Severity Engine $\to$ LLM Agent $\to$ GPS Auto-Dispatch
